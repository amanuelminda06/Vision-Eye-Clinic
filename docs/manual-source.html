1 · Start here

Sign in

  • Open the clinic's secure link: <site address>/login/<secret-path> — ask the Owner for it; any other login address shows 404
  • Enter your email + password → Sign in
  • New accounts must set a new password at first sign-in
  • Forgot your password? ask the Owner to reset it (Users → Reset password)

Global tools

  • Header Search… — type a name or phone → open a patient, sale or appointment
  • Header badges — amber = messages due, red = new website requests
  • Header menu — Change password / Sign out
  • Sidebar modules — PMS (patients/money), HRM (people), MMS (messages), CMS (website/settings)

Who can do what

  • Owner — everything: revenue, void approvals, staff/users, services, settings, templates, reports, audit
  • Reception — patients, sales, appointments, requests, follow-ups, messages, own leave; no revenue/admin
  • Staff (doctor) — dashboard, own schedule, own leave only; other pages show 403

2 · Dashboard and Daily summary

  • Dashboard — click any card to jump to its module
  • Owner cards — Revenue today / Revenue this week / Void requests / Leave requests
  • Reception cards — Appointments today / Messages due / Overdue follow-ups
  • Staff cards — My appointments today / Annual leave days left
  • Who is on duty now — live list of shifts; badges: On duty now / On leave / Not on duty
  • Daily summary (Owner) — Previous / Today / Next / Print
  • Cards — Confirmed, Voided; table — receipt number, when, patient, doctor, status, total

3 · Patients (PMS → Patients)

  • Find — search by name or phone; filter by System ID, Clinic ID, date range, Status → Filter → Clear
  • Export — CSV / Excel · Import CSV → Download template → Upload and validate → Import valid rows
  • New patient — Full name, Phone, Guardian, Sex, Age, Language, non-clinical Notes, Clinic ID → Create patient
  • Duplicate warning — check the linked patient; Save again only if it is genuinely a new person
  • Patient detail tabs — Overview / Sales / Appointments / Messages / Sick leave (if enabled)
  • Tags — type comma-separated tags → Save tags
  • Messaging — Stop messages (with reason) or Allow messages again
  • Status — Deactivate / Reactivate (record is never deleted)
  • Phone is tap-to-call; ID photo actions only when enabled in Settings

4 · Sales, receipts and Revenue (PMS)

New sale (POS)

  • Sales → New sale → search patient by name/phone and click, or tick Walk-in
  • Type a service → press Enter → set Qty → Delete removes a line
  • Choose Doctor and Payment method → check Total → Confirm sale
  • Total is calculated by the system; confirmed sales cannot be edited

Receipts and voids

  • Open a receipt number → Print A5 or Print thermal
  • Reception → Request void + reason; Owner → Approve / Reject in Void requests
  • Owner may Void sale directly; receipt shows Voided and an audit trail

Sales list and Revenue (Owner)

  • Sales list — filter by date, patient, status, payment method → CSV / Excel
  • Reception sees only their own sales for the current clinic day
  • Revenue — Today / This week / This month / Last month / Custom
  • Cards — Total revenue, Number of sales, Average sale, Voided total
  • Breakdowns — Daily trend, By service, By category, By doctor, By payment method

5 · Appointments, Follow-ups and Website requests (PMS)

Appointments

  • Views — List / Day / Week; navigate Previous / Today / Next; filter by doctor; export CSV / Excel
  • New appointment — search patient (or quick-create), choose Doctor, Service, Date, Start time, Duration, Notes → Save
  • System warns about double-booking, shifts, and approved leave — resolve before saving
  • Status flow — Scheduled → Confirmed → Completed; also No-show and Cancelled
  • Row actions — Confirm, Complete, No-show, Cancel (reason), Edit; Completed also has Create follow-up and Record sale

Follow-ups

  • Tabs — Open / Overdue / Done / Cancelled; filter by patient
  • Create follow-up — pick 2 weeks / 1 month / 3 months / 6 months or custom date + reason
  • Open rows — Mark done or Cancel

Website requests

  • Filter by status: All / New / Contacted / Converted / Declined / Spam
  • Mark contacted, Decline, Spam
  • Convert to appointment → choose Doctor, Service, notes → Book the appointment (patient matched by phone or created)

6 · Staff, Users, Schedule and Leave (HRM)

  • Staff (Owner) — Create, Edit, Deactivate/Reactivate; set Job title, Specialty, Doctor flag, public website flag, leave Entitlement, Photo
  • Users (Owner) — New user: Name, Email, Role, linked staff member, initial password (min 10 characters)
  • User actions — Edit, Set password, Reset password, Deactivate/Reactivate; you cannot deactivate your own account
  • Schedule — Previous / Today / Next; Add shift (staff, date, start, end, note); Edit / Delete on each shift
  • Templates — create weekly pattern → Apply template for a date range, or Copy last week; overlaps are skipped
  • Leave — Request leave: type, dates, half day, reason → Submit request; balance card shows Entitlement / Taken / Remaining
  • Cancel request on pending rows; CSV / Excel export
  • Leave approvals (Owner) — add a Note → Approve / Reject; owners cannot approve their own leave
  • Leave calendar (Owner + Reception) — team view by period
  • Staff role — sees only own schedule and own leave

7 · Messages and Campaigns (MMS)

  • The app never sends SMS itself — it prepares an sms: link; you send from the clinic phone and confirm in the app
  • Never include diagnoses, treatments, doctor specialties or prices in a message
  • Messages — groups: Overdue, Due now, Later today, Done today, Blocked
  • Per message: Send → Open in Messages app → send on the phone → return and mark sent
  • Statuses — Pending, Opened, Sent, Skipped, Expired, Cancelled, Blocked
  • Blocked reasons — inactive patient, no consent, opted out, invalid phone, cancelled appointment
  • Drafts — save a private message while composing; Delete removes a draft
  • Library (Owner) — archive reusable wording by title, language and category; Favorite / Archive / Reuse
  • Templates (Owner) — edit wording per language; keep Active ticked to use a template
  • Campaigns — New campaign: Name, Template (or Write your own), Message, Language mode, Delivery (Individual / Group)
  • Pick recipients by search or Advanced filter (services, language, last-visit dates) → Send → confirm the audience count
  • Group delivery — open campaign → Groups → send each group → Mark sent or Skip group with reason
  • Reports (Owner) — history by date; CSV / Excel export
  • Sidebar Messages badge counts due and overdue messages

8 · Services, Website content, Feedback, Settings, Audit (CMS)

  • Services (Owner) — New service: English/Amharic name, Category, Current price → Create service; Edit to change price (history is kept; old sales are unchanged)
  • In service edit form → Public website: tick Show this service on the website, add public descriptions, receipt labels, display order, image → Save
  • Website content — edit English and Amharic text for hero, home intro, contact, FAQ, announcements, social links, SEO → Save → Open the website
  • Feedback — Active shows a comment on the website; Inactive hides it; Delete removes it
  • Settings — Clinic name, Currency, Timezone; Working hours per day (Open / Close / Closed)
  • Messages settings — reminder time and offset, follow-up lead, recall months, SMS mode, default language, review link, campaign caps
  • Toggles — Reception may send campaigns, daily unsent email, group-send override, Patient ID photos, Patient sick leave, Auto-approve requests
  • Audit log (Owner) — filter by name/status/template/date → Filter; CSV / Excel export

9 · Public website

  • Pages — Home, About, Services, Doctors, Contact, FAQ, Privacy
  • Home shows key services, doctors on duty, announcements and approved feedback
  • Book an appointment — name, phone, preferred date, time window, service of interest, message → Send my request
  • The request appears in ERP → PMS → Appointment requests for conversion
  • Share your feedback on Contact → Owner moderates in CMS → Feedback
  • Prices and patient data are never shown on the public site

10 · Golden rules

  • Records are deactivated, not deleted — use Deactivate / Reactivate
  • Every change is audited — see Audit log
  • Patient notes are non-clinical only — no diagnoses, treatment or prescriptions
  • Messages are sent manually from the clinic phone, then confirmed in the app
  • Prices apply to future sales only — old receipts never change
  • Money is exact (2 decimals); dates follow the clinic timezone in Settings
  • Phones use Ethiopian mobile format: 09…, 07…, +2519…, +2517…
  • If a page says 403 — your role has no access; ask the Owner
